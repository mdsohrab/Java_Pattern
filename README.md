# ☕ Java Patterns

A collection of software design principles and patterns implemented in **Java**, each with clear **before / after** examples, diagrams and runnable demos.

## 📚 Contents

| Topic | Description |
|---|---|
| [🧱 SOLID Principles](SOLID/) | SRP, OCP, LSP, ISP and DIP, each with a violation, a fix, class diagrams and a demo |

## ▶️ Quick Start

```bash
git clone https://github.com/mdsohrab/Java_Pattern.git
cd Java_Pattern/SOLID
mvn compile
java -cp target/classes org.example.solid.SolidDemo
```

Requires **Java 17+**.
